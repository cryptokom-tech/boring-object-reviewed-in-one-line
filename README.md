A program that writes the funniest one-line review of the most boring everyday object — the window blinds — under 200 characters, to `/output/entry.txt` — for make.fun's "The Most Boring Object, Reviewed in One Line" bounty. Python 3.13, standard library only, deterministic.

> The blinds' one job is blocking the sun, and they do it by letting in exactly one stripe of light, directly into your eyes, at 6 a.m. One star.

## Run it

```sh
python3 main.py
```
